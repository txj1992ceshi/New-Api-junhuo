# `junhuo` 发布记录模板

本文档提供一个统一的发布记录模板。目标不是写长篇周报，而是让每次发布后都能留下最小但足够追溯的信息。

建议每次发布后复制一段模板，存到你习惯的记录位置，或者直接新增到单独的发布日志文件中。

## 模板

```md
## <日期 时间>

- 发布人：
- 分支：
- 提交：
- 镜像 tag：
- 构建目录：
- 发布目标：
- 是否改 env：否 / 是
- 是否改数据：否 / 是

### 本轮变更

- 
- 

### 发布动作

- 已上传构建目录：是 / 否
- 已完成 docker build：是 / 否
- 已替换线上容器：是 / 否
- 运行参数是否保持不变：是 / 否

### 验收

- `/api/status`：正常 / 异常
- 容器启动日志：正常 / 异常
- 渠道状态检查：正常 / 异常
- QQbot / Telegram：通过 / 未测 / 失败
- Win Codex：通过 / 未测 / 失败
- 验收时间窗：

### 结果

- 发布结果：成功 / 部分成功 / 失败
- 是否回滚：否 / 是
- 若回滚，回滚到：

### 补充说明

- 
- 
```

## 简版模板

如果只是小改动，也可以只记简版：

```md
## <日期 时间>

- 提交：
- 镜像 tag：
- 目标：
- 验收结果：
- 是否回滚：
- 备注：
```

## 建议记录的位置

可选方式：

1. 单独新建一份 `docs/junhuo-release-log.md`
2. 每次发布后追加一条记录
3. 或使用你自己的运维笔记系统，但字段尽量保持一致

## 记录原则

至少不要漏掉：

- 具体提交
- 镜像 tag
- 目标
- 测了哪些客户端
- 是否回滚

否则过几天再回头看，很容易只剩“我记得好像发过一版”。
